# sap_landscape_url_server
landscape url

### Requirement
pip install fastapi uvicorn

### Running the server

```
python main.py
```
- or
```
uvicorn main:app --reload
```
look for the terminal line reading Uvicorn running on http://127.0.0.1:8000. You can now safely paste http://127.0.0.1:8000 into your VS Code Landscape URL setting!
